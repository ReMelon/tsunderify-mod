<p align="center">
  Tsunderify is a highly configurable mod that edits your chat messages to make you sound like a tsundere!
  <br>
   <small>(With emphasis on swear replacement)</small>
</p>

<h2>Features</h2>

<ul>
  <li>Replaces swears in your messages with tsundere-style words</li>
  <li>Makes you stutter at the start of messages and appends tsundere affirmations to the end of messages, with a customizable probability</li>
  <li>Allows you to set a custom keybind to modify the message, or to always modify everything you send in chat</li>
  <li><b>Supports Hypixel's commands (<code>/pc</code>, <code>/gc</code>, etc) as well vanilla commands like <code>/msg</code>, <code>/whisper</code>, etc</b></li>
  <li>Transformations adapt to the case of your message</li>
  <li>Turns you into a true tsundere!</li>
</ul>


<p align="center"><strong>INCOMPATIBLE WITH CHAT PLUS</strong><p>
